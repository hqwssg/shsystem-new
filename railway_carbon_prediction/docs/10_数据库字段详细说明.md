## 1. 阅读说明

### 1.1 字段表列含义

| 列       | 含义                        |
| ------- | ------------------------- |
| 字段      | 数据库列名                     |
| 类型      | MySQL 数据类型与长度             |
| 空       | 是否允许 NULL：是/否             |
| 默认      | 数据库默认值；NULL 表示无默认值        |
| 键       | PK=主键，UK=唯一键，IDX=普通索引，—=无 |
| 含义      | 业务含义                      |
| 取值范围/约束 | 固定枚举、数值范围、单位、格式或外键关系      |

### 1.2 通用约定

- 月份字段统一为 `DATE`，存每月 1 日，格式 `YYYY-MM-01`；
- 时间字段为 `DATETIME`，格式 `YYYY-MM-DD HH:MM:SS`；
- 金额/排放/活动量使用 `DECIMAL`，避免浮点误差；
- 所有活动量、排放量、预测值均为非负；
- 布尔字段统一用 `TINYINT(1)`：0=否，1=是；
- JSON 字段必须存合法 JSON；写入前由应用层校验；
- 外键关系由应用层维护，数据库未建物理外键，便于平台分库/解耦。

### 2.3 异常枚举

**level 异常等级**

| 值    | 含义                    | 典型处置            |
| ---- | --------------------- | --------------- |
| 正常   | 未命中异常阈值               | 不处理             |
| 关注   | 轻度偏离/单通道/日历可解释        | 进 watch 监控，不进复核 |
| 异常   | 达到异常阈值                | 进复核队列           |
| 严重异常 | 得分≥0.75、分位≥99，或绝对 z>5 | 优先复核            |

**category 异常类别**

| 值            | 含义          | 说明             |
| ------------ | ----------- | -------------- |
| C1           | 单点数据错误/尖峰   | 抄表、录入、单点跳变     |
| C2           | 连续漂移/质量台阶   | 计量通道异常、连续离群    |
| C3           | 真实业务跃变/结构断点 | 机车退役、供热调整、疫情冲击 |
| C4           | 季节峰谷        | 供暖季、春节等正常峰谷    |
| UNDETERMINED | 统计异常但业务证据不足 | 按严重程度进复核或监控    |

**status 复核状态**

| 值           | 含义          |
| ----------- | ----------- |
| pending     | 待人工复核       |
| approved    | 已复核通过       |
| rejected    | 已驳回（保留原始状态） |
| auto_closed | 历史数据自动处置并关闭 |

**final_disposition 最终处置**

| 值               | 含义        | 对活动数据                       | 对训练         |
| --------------- | --------- | --------------------------- | ----------- |
| keep            | 保留原值      | quality=valid               | 进入训练        |
| correct         | 修正为指定值    | 更新 value/reported_value     | 进入训练        |
| exclude         | 排除该点      | quality=excluded            | 不进入训练       |
| mark_breakpoint | 保留原值并标记断点 | data_flag=MANUAL_BREAKPOINT | 进入训练，作为断点解释 |

**channels/context_flags**

- `channels`：`raw`、`resid`、`joint`、`rule` 及其组合，如 `raw+resid+joint`；
- `context_flags`：`spring_festival`、`covid`、`maintenance`，逗号分隔；空串表示无上下文。

## 6. 数据状态流转

### 6.1 活动数据

```text
接入/导入 → quality_status=valid
新增单点命中异常 → quality_status=pending → 复核
复核 keep/correct → quality_status=valid
复核 exclude → quality_status=excluded
```

### 6.2 异常

```text
V2 检测 → 复核级 auto_closed（历史） / pending（新增）
pending → approved（keep/correct/exclude/mark_breakpoint）
pending → rejected（保留原值，需说明）
关注级 → prediction_anomaly_watch（无复核状态）
```

### 6.3 批次

```text
received → validated → pending_review（有异常）
pending_review → completed（全部复核）
received/validated → rejected（校验失败）
```

## 8. 使用与扩展注意事项

1. 新增品种需先在 `prediction_energy_var` 注册单位、类别，再写活动数据；
2. 新增排放因子/供热系数必须写生效期，禁止直接改历史值；
3. 修改活动数据必须同步重算 `prediction_emission_monthly`；
4. 训练只使用 `quality_status=valid` 的月份；
5. JSON 字段（feature_order/scaler_state/metrics/config）必须保持向后兼容；
6. 预测结果写入前校验 `lower_bound ≤ point ≤ upper_bound`；
7. 异常复核必须写 `prediction_anomaly_audit`，禁止物理删除；
8. 生产环境建议给本模块单独数据库账号，只授予 `prediction_*` 读写权限。

## 9. 常用校验 SQL

**9.1 活动数据唯一性**

```sql
SELECT org_id, period, var_id, COUNT(*) AS n
FROM prediction_activity_monthly
GROUP BY org_id, period, var_id
HAVING n > 1;
```

**9.2 排放总量恒等式**

```sql
SELECT org_id, period
FROM prediction_emission_monthly
WHERE ABS(total_reported_tco2 - (gas_tco2 + gasoline_tco2 + diesel_tco2 + electricity_tco2 + heat_tco2)) > 0.01;
```

**9.3 预测区间合法性**

```sql
SELECT id, org_id, period
FROM prediction_forecast
WHERE lower_bound > point OR point > upper_bound OR point < 0;
```

**9.4 冠军模型唯一性**

```sql
SELECT org_id, COUNT(*) AS n
FROM prediction_model
WHERE is_champion = 1
GROUP BY org_id
HAVING n > 1;
```

**9.5 异常状态一致性**

```sql
SELECT id, org_id, period, var_id
FROM prediction_anomaly
WHERE (status = 'pending' AND final_disposition IS NOT NULL)
   OR (status IN ('approved','auto_closed') AND final_disposition IS NULL);
```

**9.6 批次待复核数量**

```sql
SELECT detect_batch_id, COUNT(*) AS pending_n
FROM prediction_anomaly
WHERE status = 'pending'
GROUP BY detect_batch_id;
```
