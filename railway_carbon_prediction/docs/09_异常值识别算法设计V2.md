# 异常值识别算法设计 V2

**版本**：V2.0
**适用范围**：朔黄铁路机辆、肃宁、原平三个分公司 2019—2025 年月度碳排放数据
**检测对象**：电力总和、柴油、天然气、汽油、可比口径总排放
**实现位置**：`src/carbon_prediction/anomaly_v2.py`、`pipeline.py`
**数据表**：`prediction_anomaly`、`prediction_anomaly_watch`、`prediction_anomaly_calibration`、`prediction_calendar_event`

---

## 1. 方法总览

本方案采用“逐品种稳健统计 + 双通道孤立森林 + 月度断点检测 + 日历/多变量证据”的组合检测方法，并按“复核级/关注级”分流处置。

```
月度活动数据
   │
   ├─ 逐品种 STL 分解 → MAD 修正 z
   ├─ raw 通道孤立森林
   ├─ resid 通道孤立森林
   ├─ 月度断点检测（CUSUM 思想 + 池化统计量）
   ├─ 多变量联合孤立森林（佐证）
   └─ 日历事件（春节/疫情/检修）
   │
   ▼
C1—C4 分类
   │
   ├─ 复核级：异常/严重异常 → prediction_anomaly
   └─ 关注级：关注 → prediction_anomaly_watch
```

设计原则：

1. 逐品种建模，避免小量级品种被大品种淹没；
2. 先季节分解，再对残差做稳健统计；
3. 断点必须在月度粒度识别；
4. 确定性序列由规则判定，不强行做统计检测；
5. 复核级与关注级分开，关注级不占用人工复核队列；
6. 原始值不删除、不自动修正，处置全程留痕。

## 3. 逐品种 STL 残差与 MAD 修正 z

### 3.1 STL 分解

对每个组织×品种序列做稳健 STL：

```
y_t = T_t + S_t + R_t
```

- `T_t`：趋势项；
- `S_t`：季节项（period=12）；
- `R_t`：残差项，作为稳健统计的输入。

参数：`period=12`、`robust=True`。

### 3.2 MAD 修正 z

```
med = median(R)
MAD = median(|R − med|)
σ = 1.4826 × MAD
z = (R − med) / σ
```

判定：

- `|z| > 3`：该月为该品种的离群点；
- `|z| > 5`：升级为严重异常；
- 若 `MAD = 0`，退化为残差标准差；仍为 0 则跳过该序列。

MAD 不受极端值支配，适合天然气、柴油等含台阶的序列。

### 3.3 连续段与复现

- **连续段长**：以 `|z| > 3` 为标记，统计该点前后连续离群月数；
- **同月同向复现**：同一月份、同一 z 符号、在 ≥2 个年份出现 `|z| > 3`，可作为季节峰谷证据。

连续段长 ≥6 时，不判为 C4 季节峰谷，避免整年台阶被季节解释放行。

## 4. 双通道孤立森林

### 4.1 通道划分

| 通道    | 输入特征                                       | 作用           |
| ----- | ------------------------------------------ | ------------ |
| raw   | 原值、环比、同比、3 期滚动均值/标准差、月份正余弦、日历哑变量           | 捕捉量级异常       |
| resid | STL 残差、残差 z、绝对残差 z、残差 3 期滚动标准差、月份正余弦、日历哑变量 | 捕捉剔除季节后的形态异常 |

两通道分别训练：

```python
IsolationForest(
    n_estimators=200,
    max_samples="auto",
    contamination=0.05,
    random_state=20260928,
    n_jobs=1,
)
```

### 4.2 得分与触发

```
raw_score   = -raw_model.score_samples(raw_X)
resid_score = -resid_model.score_samples(resid_X)
```

各通道取 `95%` 分位为触发阈值：

```
raw_flag   = raw_score   ≥ quantile(raw_score, 0.95)
resid_flag = resid_score ≥ quantile(resid_score, 0.95)
both       = raw_flag and resid_flag
```

`both=True` 表示量级异常与残差形态异常同时成立，作为升级为“异常/严重异常”的依据之一。

### 4.3 通道组合

| 组合          | 含义        | 处理              |
| ----------- | --------- | --------------- |
| raw + resid | 双通道一致     | 升级              |
| 仅 raw       | 量级异常，残差正常 | 可能为季节解释，转 C4 候选 |
| 仅 resid     | 形态异常      | 结合 MAD z 与断点判断  |
| 仅 joint     | 多变量联合触发   | 只作佐证，不单独产出异常    |

## 5. 月度断点检测

### 5.1 定位统计量

对每个候选切点 `t`（左右各至少 6 个月）：

```
pooled_std = sqrt[((nL−1)·varL + (nR−1)·varR) / (n−2)]
stat = |meanR − meanL| / pooled_std × sqrt(nL·nR/n)
shift_pct = (meanR − meanL) / |meanL| × 100
CV_L = stdL / |meanL|
CV_R = stdR / |meanR|
```

取 `stat` 最大的切点为候选断点。

### 5.2 三判据

同时满足以下三条才判断点：

| 判据     | 阈值                      | 作用                  |
| ------ | -----------------------:| ------------------- |
| `stat` | ≥ 3.0                   | 排除噪声                |
| `      | shift_pct               | `                   |
| `CV_R` | ≤ `CV_L × 1.5`，或断点后均值≈0 | 要求断点后进入新稳态，排除数据质量台阶 |

断点后 3 个月为过渡窗，只有窗内点才标 C3。

### 5.3 断点输出

| 字段                   | 说明             |
| -------------------- | -------------- |
| breakpoint_date      | 断点月            |
| breakpoint_stat      | 定位统计量          |
| shift_pct            | 水平位移百分比        |
| cv_ratio             | 后段 CV / 前段 CV  |
| in_breakpoint_window | 是否在断点后 3 个月过渡窗 |

## 7. 多变量联合检测

联合变量：

```
ELEC_TOTAL, DIESEL, GAS, GASOLINE, TURNOVER
```

处理：

1. 按组织透视成月度宽表；
2. 各变量标准化；
3. 加入月份正余弦；
4. 训练孤立森林，取 95% 分位为 `joint_flag`。

联合通道的定位是**佐证**：

- 与单通道同时触发时，提高异常置信度；
- 不单独产出异常，避免天然气、汽油等小量级品种被电力等大品种淹没；
- 联合得分写入 `joint_score`，供复核参考。

## 8. 确定性热力序列

热力由供热面积、供热月份、计费方式决定，属于确定性序列。统计检测会把零值月和档位跳变误判为异常，因此：

- `HEAT` 不进入 STL/MAD/森林检测；
- 已知年度供热调整以规则事件登记为 C3；
- 事件值取自年热力总量变化，写入 evidence。

## 9. 分类规则

### 9.1 判定顺序

```
断点窗内 → C3
  ↓ 否
季节可解释/同月同向复现 → C4
  ↓ 否
连续段 ≥6 → C2（质量台阶）
  ↓ 否
|z|>3 且连续段≤1 → C1（单点）
  ↓ 否
|z|>3 且连续段 2—5 → C2（连续漂移）
  ↓ 否
未定类 → UNDETERMINED
```

### 9.2 类别定义

| 类别  | 含义        | 典型原因              | 处置      |
| --- | --------- | ----------------- | ------- |
| C1  | 单点数据错误/尖峰 | 抄表、录入、单点跳变        | 保留/修正   |
| C2  | 数据质量/连续漂移 | 计量通道、台阶、连续异常      | 标记断点/复核 |
| C3  | 真实业务跃变    | 机车退役、供热调整、疫情/需求冲击 | 标记断点    |
| C4  | 季节峰谷      | 供暖季、春节            | 保留，进关注级 |

### 9.3 复核准入

| 条件           | 是否进复核  |
| ------------ | ------ |
| C3 断点        | 是      |
| 规则登记事件       | 是      |
| 天然气：严重且连续段≥6 | 是      |
| 天然气其他        | 否，进关注级 |
| 汽油           | 否，进关注级 |
| 日历可解释且连续段<6  | 否，进关注级 |
| 其他严重异常       | 是      |
| 双通道且         | z      |
| 其他           | 否，进关注级 |

## 10. 复核与监控分流

### 10.1 复核级

写入 `prediction_anomaly`，字段包括：

- 得分：`score/raw_score/resid_score/joint_score`；
- 通道：`channels`；
- 日历：`context_flags`；
- 断点：`breakpoint_date/stat/shift_pct/cv_ratio/in_breakpoint_window`；
- 证据：`evidence`；
- 处置：`suggested_disposition/final_disposition/status`。

历史数据自动 `auto_closed`；新增数据进入 `pending`，人工复核后更新。

### 10.2 关注级

写入 `prediction_anomaly_watch`，字段包括：

`org_id/period/var_id/level/category/score/channels/context_flags/evidence`。

关注级不进入复核队列，主要用于月度数据质量报告。

### 10.3 新增单点

新增数据使用同月稳健 z：

```
base = 同月历史（≥3 年），否则最近 24 个月
med = median(base)
σ = 1.4826 × median(|base − med|)
z = (value − med) / σ
outside = value > max(history)×1.2 或 value < max(0,min(history)×0.8)
```

分流：

| 条件     | 分流  |
| ------ | --- |
| `      | z   |
| `2.5 < | z   |
| `      | z   |

## 11. 阈值校准方法

### 11.1 标签构造

以历史复核/规则处置结果为弱标签：

- 正样本：历史复核级中类别为 C1/C2/C3 的点；
- 负样本：同序列其余月份；
- 标签仅用于阈值评估，不作为 ground truth。

### 11.2 校准过程

对每个组织×品种：

1. 计算 V2 双通道得分 `score = max(raw_score, resid_score)`；
2. 在 `q ∈ {0.90,0.92,0.95,0.97,0.98,0.99}` 上取分位阈值；
3. 计算 Precision、Recall、F1；
4. 取 F1 最大的分位作为推荐阈值；
5. 写入 `prediction_anomaly_calibration`。

### 11.3 本期校准结果

最近一次校准共 12 行，覆盖正例≥2 的序列：

| 组织  | 变量   | 推荐分位 | 阈值       | Precision | Recall | F1   | 正例/负例 |
| --- | ---- | ----:| --------:| ---------:| ------:| ----:| -----:|
| 机辆  | 电力总和 | 0.98 | 0.648548 | 1.00      | 1.00   | 1.00 | 2/82  |
| 机辆  | 天然气  | 0.97 | 0.640645 | 1.00      | 1.00   | 1.00 | 3/81  |

## 13. 适用条件

1. 月度序列长度不少于 24 个月；
2. 关键品种有连续月度记录，缺失值仅用于 STL 插值；
3. 供热、检修等确定性事件有规则或业务登记；
4. 新增数据接入后先做异常检测，再进入训练；
5. 复核级与关注级分开管理，关注级用于质量报告，不直接阻断建模。
