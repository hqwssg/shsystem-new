# 机车牵引计算数据落库说明

本文件说明 `data/real_shuohuang/locomotive_curves.json` 的内容、来源与使用注意事项。

## 数据来源

- 标准：**TB/T 1407.1—2018《列车牵引计算 第1部分：机车牵引式列车》**（2018-11-01 实施，替代 TB/T 1407.1—1998）。
- 文件：`shuohuang_data/TBT1407.1-2018FDIS.pdf`（纯扫描件，155 页，无文字层）。
- 取点方式：逐页渲染 → 裁剪放大 → 人工读点，写入 JSON。
- **PDF 页码映射：物理页索引 = 标准页码 + 4**。

## 关键结论：SS₄ 系列是电阻制动，不产生再生电量

这是本次落数据最重要的发现，直接影响算法假设：

- 标准 4.9.1 把「电力机车**电阻制动**」与「电力机车**再生制动**」明确分开。
- 附录 L 标题是「各型**交流传动**电力机车再生制动发电电流曲线图」，只收交流传动机车（HXD₁ 等）。
- **SS₄ / SS₄(改) / SS₄B 是直流传动（相控调压），制动能量通过电阻柜耗散，不回馈牵引网。** JSON 中这三型 `regenerative: false`。
- 只有 HXD₁ / HXD₁B（神华号同平台，交流传动）才有 `regenerative: true` 和电流曲线。

因此，如果朔黄存在 SS₄B 担当的列车，项目当前「所有列车都按有再生能量」的假设会在这些列车上系统性高估再生量。需要在下一步给 `trains.csv` 增加机车类型字段来区分。

## 数据精度说明

- 附录 B 表格值是**权威数据**，取点误差约 ±1%（主要是小数位辨认）。
- 附录 F 曲线图是**示意图**，取点误差约 ±3%；本次电制动力统一以附录 B 表格值为准，附录 F 仅作形态参考。
- 附录 L 电流曲线取点误差约 ±3%。

## 当前项目与标准的差距（落库后发现）

| 项目当前 | 标准 | 影响 |
| --- | --- | --- |
| `max_brake_kN` 是常数（重车 6200 kN） | 电制动力随速度变化，且分电制动/空气制动 | 低速段再生能量高估约 3 倍 |
| 电制动功率上限用 `max(牵引力,制动力)×5` 估算 | 电制动按曲线取值，超出部分归空气制动 | 同上 |
| `default_adhesion_coefficient = 0.28` 常数 | 分速度、分干湿、分有无防滑的公式 | 雨天可行性被高估 |
| Davis 阻力系数 `8.0/0.10/0.0028` 直接当 kN | 表2/表5 是「单位基本阻力 N/kN」，需乘质量 | 基本阻力算小约 34 倍 |
| 无机车类型字段，全部按有再生 | SS₄ 系列是电阻制动 | 选题层面风险 |

- **附录 H（电力机车牵引特性曲线图）**：牵引力曲线，与表 B 的黏着牵引力数据重叠，未单独取点。

### 已生效的行为

- 电制动功率 = `min(需求制动力, 机车台数 × B_d(v)) × v`，超出部分归空气制动。
- **电阻制动机车（SS₄ 系列）再生能量归零**（已验证：切换 SS4B 后再生 = 0 kWh）。
- 基本阻力 = 机车阻力（表2系数 × 机车质量）+ 货车阻力（表5系数 × 货车质量），均按 N/kN × 质量 × 9.81/1000 折算。
- 牵引黏着力上限 = 黏着系数 × 机车黏着重量（表10）× 9.81 × 安全系数；**只有机车参与牵引黏着**，货车不计入。
- 电气功率上限 = 机车台数 × 单台持续功率（表10 持续牵引力 × 持续速度推导），HXD₁ 约 9600 kW/台。
- 制动黏着力上限仍按整列车质量 × 制动黏着比例计算（货车闸瓦也参与制动）。
- 未配置 `locomotive_type` 时回退旧逻辑（向后兼容）。

### 再生电量的两条独立路径（可互校）

| 路径 | 口径 | 用途 |
| --- | --- | --- |
| 力学折算 | 电制动力 × 速度 × 有效时长积分 | 当前下游结算使用 |
| 式(72) 电流积分 | `Q_z = U_w·Σ(I_z·t_z)/60`，I_z 查附录 L | 独立校核 |

校核工具：`python tools/verify_regen_energy_paths.py --output-dir outputs/regen_path_check`

当前结果（U_w=25 kV）：

| 车次 | 力学折算 | 式(72) | 偏差 |
| --- | ---: | ---: | ---: |
| Heavy（HXD₁×4） | 39,148.9 kWh | 42,514.3 kWh | +8.6% |
| Empty（HXD₁×2） | 186.2 kWh | 178.2 kWh | −4.3% |

两路径差异在 10% 以内，说明电制动/机械制动划分基本合理。若 U_w 改用 27.5 kV，式(72) 结果整体 +10%（Heavy 约 46,766 kWh，偏差扩到 +19.5%）——**这正是必须等甲方实测电压的原因**。

### 关键发现：量级变化与机型开关

- **Davis 量纲修正**是影响最大的改动：基本阻力从约 10 kN 修正到约 350 kN（重车 60 km/h），重车牵引能耗从约 4444 kWh 修正到约 6 万 kWh 量级——之前「重车一路下坡几乎不牵引」是错误的，修正后重车下坡也需牵引克服阻力。
- **电制动曲线限幅对总量影响小（约 0.2%）**：朔黄重车需求制动力中位数约 1089 kN，低于 4 台 HXD₁ 的电制动能力 1844 kN。
- **真正影响再生量的是机型选择**——SS₄B（电阻制动）再生归零 vs HXD₁（再生制动）全量回收，差 6 万 kWh 量级。
- 机车/货车分开建模的影响约 1-4%（机车质量占比小）。
