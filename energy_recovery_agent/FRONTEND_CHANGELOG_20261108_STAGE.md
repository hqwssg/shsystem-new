# 阶段联调包变更

比较基准为 `frontend_backend_code_20261108_v1`。数据库接口冻结版本仍为 `1.6.0`。

- 实绩运行图按原区间起始和结束时间分别生成出发和到达。跨站时长必须为正，运行弧必须覆盖原区间。
- 同向始发间隔预检能列出调整范围内必然无法满足间隔的车次对。遇到此情况，保留基线诊断并跳过搜索。
- 重空调度搜索在既有种群预算内纳入相位下界，减少遗漏可行发车组合的情况。
- 优化器保留独立基线评分。基线不可行时，返回 `no_feasible_solution` 与 `baseline_infeasible`，购电改善等字段留空。
- 重空调度报告按实际生效的储能参数和假设等级展示。调度恢复可行性时，原基线的能耗留作诊断，节能百分比为空。
- 包清单和能力矩阵按仿真阶段锁定正式结论。真实提取、工程假设和虚拟配置分别查看数据来源与假设登记。补机电量占比来自不同趟样本的分组推算。
- 数据库投影区分柔性供电设施和储能设备。仅含柔性供电区间的数据版本仍可运行阶段仿真，设备台账随正式设备资料补齐。
- 滚动重调度示例按当前 145 kWh 冻结容量分配设备 SOC，储能规划示例引用冻结运行视图中的真实供电臂编码，避免联调输入自相矛盾。
- 资源冲突的单点里程转换成数值入库，区间范围保留在冲突说明和原始结果中。
- 绘图依赖固定为 Pillow 13.0.0。独立安装使用带哈希的锁文件。
- 新增 `database/mysql_module_comments.sql` 和 `docs/algorithm_database_design_zh.md`，覆盖当前 `bb.sql` 中 48 张算法模块表、611 个字段的中文注释和设计说明。
