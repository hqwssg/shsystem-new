# 生产运行保障配置

本目录保存不含凭据的生产运行保障策略和进程参数模板。正式连接串必须由部署环境的密钥系统注入，不得写入本目录、日志或交付压缩包。

| 文件 | 用途 |
| --- | --- |
| `production_assurance_policy.json` | 部署前监控阈值、worker约束、备份恢复检查项和外部验收边界 |
| `production_worker.env.example` | 常驻worker的非敏感进程参数模板 |

策略中的阈值是当前规划/合成数据和本地硬件上的工程回归线，不是生产SLA。目标环境到位后必须依据正式负载重新批准并升级`policy_version`。
