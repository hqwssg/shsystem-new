# 项目说明核心包

本包只包含理解当前项目所必需的四份文档：

1. `00_项目摘要与阅读顺序.md`：先看结论，再决定是否深入。
2. `01_项目详细说明.md`：项目目标、模型、算法流程、代码结构和当前限制。
3. `02_算法核心说明.md`：能量回收、储能 SOC、列车调度和运行图优化的核心逻辑。
4. `03_数据与正式结论边界.md`：当前数据状态、正式数据缺口和结果使用边界。

推荐只阅读前两份即可掌握项目全貌；需要理解算法时再阅读第三份；需要判断能否正式汇报时阅读第四份。

本包不包含历史资料、论文资料、专项测试、API 参考、性能报告、结果快照和重复说明。这些资料仍保留在项目仓库中，但不属于当前项目情况说明包。
