# 小规模精确最优与启发式差距基准

更新时间：2026-09-07

## 1. 目的

本基准对应论文实验 E12 中此前缺失的“小规模精确解与 optimality gap”部分。它回答：在完全相同的候选域、可行性规则和目标口径下，当前 NSGA-II 能否找到可行解，以及找到的解距离可证明最优值有多远。

## 2. 精确性范围

完整能源结算、SOC、电气和多场景资源检查包含离散仿真，当前资源 MILP 只负责资源可行性，不能直接证明完整能源目标最优。因此本基准采用有限候选域完全穷举：逐一评价笛卡尔积中的每个候选，以其中最优者作为该显式离散域内的全局最优解。

默认域为：

| 决策变量 | 值 |
| --- | --- |
| 重车追踪间隔 | 3000、3300秒 |
| 空车追踪间隔 | 2700、3300秒 |
| 重空相位 | 2300、2600、2760秒 |
| 储能区停车 | 0、180秒 |
| 储能对齐偏移 | 0、300秒 |
| 储能预设 | 固定为 `virtual_two_section_base` |

每个规模共48个候选。固定储能预设是为了隔离运行图启发式本身的求解质量。这里的“全局最优”不能外推到连续时间、逐列车任意偏移、其他储能预设或未列出的变量值。

## 3. 公平比较规则

- 精确法与启发式共享同一评分表，保证数值评价完全一致；
- 两者均使用正常、重车轻度延误、空车轻度延误和两个非核心压力场景；
- 前三个核心场景必须全部通过资源、信号、电气、能量、SOC和服务数量约束；
- NSGA-II 的交叉和变异结果会吸附到声明的离散域，不允许越界候选参与比较；
- 最优方案按生产 `energy_first` 词典序选择键确定；
- `optimality gap` 针对首要能源目标 `grid_kwh + effective_regen_loss_kwh` 计算；
- 启发式未找到可行解时，差距记为未定义并单独计入可行命中率，不能伪记为0%。

## 4. 执行

```powershell
python run_project.py benchmark-small-optimality-gap
```

默认测试2、4、6列车，随机种子为11、23、37、53、71，并比较 `quick`、`standard`、`large` 三档搜索预算。长测按规模写入 `benchmark_progress.json`。

## 5. 输出

结果目录为 `paper/experiments/E12_small_scale_optimality_gap/`：

| 文件 | 内容 |
| --- | --- |
| `benchmark_summary.json` | 实验边界、配置、精确解、分档结果和总计 |
| `exact_candidates.csv` | 每个规模全部穷举候选和完整评分 |
| `heuristic_runs.csv` | 每个规模、档位和随机种子的差距与命中情况 |
| `optimality_gap_by_scale.png` | 分规模差距图 |
| `SMALL_SCALE_OPTIMALITY_GAP_REPORT.md` | 中文结论报告 |

正式数据到位后必须冻结候选域、随机种子、搜索预算和数据版本，按相同命令重跑；不得根据结果临时调整候选域后仍把两轮结果当成同一实验。
