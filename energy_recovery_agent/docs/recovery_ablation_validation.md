# 扰动恢复第五阶段：恢复机制消融对照

更新时间：2026-09-08

## 1. 阶段目标

第五阶段回答“恢复机制是否真正改善多轮滚动结果”，而不只证明恢复代码能够运行。实验在相同规划数据、初始SOC、四轮扰动、随机种子、候选预算、预测时域和执行窗口下运行两个分支：

- 控制组：关闭常规搜索之后的局部恢复和精确MILP恢复；
- 恢复组：开启完整的局部与精确恢复级联。

两组都保留相同的常规候选搜索、稳健场景评价、计划/实际运行图区分、执行锁定和SOC结算。因此唯一策略差异是恢复级联是否参与。

为保留原始反事实传播，第五阶段两组均显式设置 `allow_infeasible_commit_for_experiment=true`。这是研究模式，不是生产默认行为；生产提交门禁的独立验证见 `rolling_infeasible_commit_gate.md`。

## 3. 能量指标解释

能量只累计互不重叠的实际执行时间片，不累计彼此重叠的预测窗口。当前恢复组购电量少444.725737 kWh，但控制组第2至4轮不是核心稳健可行方案，两组不属于“同等可行方案”的节能对照。该数值只能说明恢复动作改变了执行轨迹和能量账本：恢复采用规则首先保证可行性，并没有为了获得该购电差而选择方案。正式论文不能把这一数值作为现场节能率，也不能由单次固定种子推断统计显著性。

## 4. 自动门禁

对照实验及独立核验要求：

1. 两组外生输入、搜索配置和随机种子完全一致；
2. 关闭组的局部/精确恢复均不触发，开启组至少触发并采用一次；
3. 两组状态推进、SOC连续、实际发车锁定和服务数量门禁均通过；
4. 开启恢复不减少核心稳健可行轮次，并至少恢复一个控制组不可行轮次；
5. 开启恢复减少核心场景冲突或约束违反量；
6. 两组执行期能量指标完整、有限且按同一口径计算；
7. 独立核验器从两个分支原始汇总重新计算可行轮次、冲突、违反量和能量差。

当前所有门禁通过，独立核验结果为 `valid=true`。

## 6. 结论边界

控制组继续提交不可行回退只用于观察缺少恢复时的连锁影响，不是可上线执行策略。当前车辆、线路、信号、电气和储能参数仍含规划或工程占位值；正式数据到位后，需要用历史扰动回放和多个随机种子重做该消融实验，并报告均值、离散程度、置信区间以及恢复成功率。
