# 项目说明核心包阅读导航

本包只保留理解当前项目所必需的 8 份文档，不包含历史资料、论文资料、专项测试报告、结果快照或重复说明。

## 推荐阅读顺序

1. `00_项目摘要.md`：快速了解项目目标、能力、限制和当前结论。
2. `01_项目详细说明.md`：了解模型、算法流程、代码结构和输入输出。
3. `02_算法边界与当前状态.md`：确认算法负责什么、目前做到什么程度。
4. `03_数据缺口与正式数据.md`：确认哪些结论必须等待甲方或设备厂家数据。
5. `04_算法实现说明.md`：深入能量结算和调度实现。
6. `05_运行图优化器.md`：深入运行图候选和优化目标。
7. `06_最小正式数据包.md`：了解正式数据接入的最小要求。

## 文档之间的关系

摘要回答“项目是什么”；详细说明回答“项目怎么工作”；边界与状态回答“现在能不能正式使用”；数据文档回答“还缺什么”；算法实现和运行图文档回答“代码具体怎么做”。

## 当前结论

算法原型、能量结算、重空调度、运行图优化、约束检查、结果审计和测试体系已经形成。当前不能发布正式节能率、储能容量或投资收益结论，因为车辆、储能、供电、正式运行图和部分信号资源数据尚未全部确认。
