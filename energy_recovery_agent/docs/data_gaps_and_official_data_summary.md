# 数据缺口与正式数据总结

## 仍需甲方或设备厂家确认的数据

- 正式运行图、车站名称和到发时刻；
- 车辆质量、牵引力、制动力、牵引/制动曲线和 Davis 阻力参数；
- 供电臂边界、牵引供电能力和再生吸收能力；
- 储能容量、最大充放电功率、效率、SOC 范围、成本和接入区段；
- 闭塞分区、追踪间隔、站场咽喉、股道和区间容量；
- 初始车流库存、运输任务和 OD；
- 智能电表方向码、站区间映射和计量质量信息。

## 当前数据能做什么

当前混合数据可用于运行流程、接口、约束、能量守恒、鲁棒性和候选排序测试，也可进行参数区间扫描。

## 当前数据不能支持什么

不能支持正式节能率、绝对能耗、储能容量定型、设备投资收益或现场运行可执行性结论。

## 正式数据到位后的最短流程

```text
接收数据和来源证明
→ 数据门禁与字段校验
→ 替换规划/虚拟参数
→ 重建派生数据
→ 运行测试和能量审计
→ 重新运行基线与优化方案
→ 与实测或正式运行图对比
```
