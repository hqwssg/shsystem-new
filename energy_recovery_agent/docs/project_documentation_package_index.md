# 项目说明包阅读导航

本说明包面向需要快速了解项目、输入、输出和当前限制的读者。文档按“先总览、再查细节”组织，不包含历史实验报告、重复的测试记录或已淘汰方案。

## 推荐阅读顺序

1. `01_项目总体说明.md`：项目目标、边界、当前成熟度和正式决策门控。
2. `02_输入数据说明.md`：运行图、车辆、供电臂、储能、资源和运输任务的输入来源与状态。
3. `03_输出结果说明.md`：各命令生成的文件、关键指标和基线/优化结果的解释。
4. `04_参数说明.md`：主要物理、结算、约束和优化参数的单位、作用与当前取值性质。
5. `05_算法实现与决策逻辑.md`：能量回收、调度优化、约束检查和“是否优化”门控的实现逻辑。
6. `06_正式数据与结论边界.md`：哪些数据仍待甲方确认，以及正式数据到位后的验收流程。

## 一句话定位

这是一个用于评估再生制动能量回收能力、并在有实质节能空间时优化重空列车运行图的算法原型；没有实质改善时应保留现有运行图。当前结果可用于流程验证和相对比较，不能替代正式工程结论。
