## 2. 状态解释

- `current_authority` 文档可以用于判断当前项目状态；
- 专项报告只证明特定测试或阶段，不覆盖当前状态基线；
- 当前软件完成部署前本地验证，但仍为 `production_accepted=false`；
- 当前数据为 `planning_placeholder`，不能发布正式节能率、储能容量或线路容量结论。

## 3. 完整性核验

包根目录的 `DOCUMENTATION_MANIFEST.json` 记录每份文档的来源、分类和 SHA-256；`CHECKSUMS.sha256` 用于核对解压文件。构建与验证入口分别是：

```powershell
python tools/build_project_documentation_package.py
python tools/verify_project_documentation_package.py
```
