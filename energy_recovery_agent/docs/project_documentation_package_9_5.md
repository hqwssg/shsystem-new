# 《项目说明文档-9.5》阅读导航

本包对应算法发布基线 `2026.09.11.5` 及 2026-09-11 安全审计、干净环境和独立长测后的当前工作区状态，按“先看结论，再查细节”组织。上一正式冻结基线仍为 `2026.09.11.5`；安全加固候选尚未形成新正式发布，原因见安全审计文档。

## 1. 建议阅读路径

### 只想了解项目现状

1. `00_先读/00_阅读导航.md`；
2. `00_先读/01_当前状态基线.md`；
3. `00_先读/02_算法边界与交付物.md`。

继续阅读输入输出说明、参数说明、数据库表结构、数据库集成指南和平台接口冻结说明。

### 需要理解算法或核验结论

继续阅读算法实现说明、API参考、算法可信边界以及数据缺口与后续动作。

### 需要准备部署和运维

继续阅读生产保障工具包说明、生产验收清单以及依赖安全与SBOM说明。安全审计当前为阻断状态，不能仅凭算法功能测试通过进行生产发布。

## 2. 状态解释

- `current_authority` 文档可以用于判断当前项目状态；
- 专项报告只证明特定测试或阶段，不覆盖当前状态基线；
- 当前软件仍为 `production_accepted=false`；
- 当前数据为 `planning_placeholder`，不能发布正式节能率、储能容量或线路容量结论；
- 当前候选已完成Python 3.11/3.12干净环境、依赖锁验证及Python 3.12下7项独立长测；旧正式v5仍保留Python 3.9/Pillow风险记录，新生产发布还需候选冻结、统一发布验收和目标环境验收。

## 3. 完整性核验

包根目录的 `DOCUMENTATION_MANIFEST.json` 记录每份文档的来源、分类和 SHA-256；`CHECKSUMS.sha256` 用于核对解压文件。构建与验证入口分别是：

```powershell
python tools/build_project_documentation_package.py
python tools/verify_project_documentation_package.py
```
