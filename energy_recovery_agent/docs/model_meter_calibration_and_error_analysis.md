# 模型结果—电表数据校准与误差分析链路

更新时间：2026-09-04

## 1. 目标与边界

该链路用于回答“列车运行能量模型与可匹配电表数据的一致性如何”，并为正式实验提供可追溯的模型验证证据。它不直接证明优化后的现场节能量，也不会把校准系数自动应用到运行图优化器。

校准对象当前是牵引电量。再生电量、供电臂总表、储能侧电表和网侧购电若要分别校准，必须取得各自明确的计量边界、时间戳、设备归属和损耗口径后建立独立账本，不能用牵引系数替代。

## 2. 完整处理链路

```text
原始电表/站点任务数据
  → 时间窗和 trainid 匹配
  → 重叠、重复、边界缺口和能量不一致诊断
  → 代表性样本筛选
  → 站点、运行弧、方向和线路基础数据对齐
  → 未校准误差统计
  → fit_core 鲁棒样本筛选
  → 外部独立验证文件，或分层确定性拟合集/留出集拆分
  → 仅用拟合集估计全局和分组系数
  → 留出集 MAE/RMSE/偏差/MAPE/P90/WAPE/R² 验证
  → 样本量、误差、改善幅度和系数范围质量门禁
  → 通过后生成系数；显式要求时才发布
  → 正式实验总控记录校准摘要和 SHA-256
```

默认筛选只保留主线、可映射、非零牵引样本。短站间、低强度、单表、边界缺口、零电量和极端比例样本仍输出供诊断，但不进入默认 `fit_core` 系数拟合。

优先使用不同日期或不同来源批次形成的外部对齐表作为验证集。程序会检查拟合集与外部验证集的稳定样本标识是否重叠，发现重叠即阻断发布。暂时只有一批数据时，才退回按方向和电表聚合口径分层的确定性留出验证。

## 3. 状态含义

| 字段/状态 | 含义 |
| --- | --- |
| `pipeline_completed=true` | 所有可执行的匹配和诊断步骤已完成，不代表校准可信 |
| `valid=true` | 独立留出验证及全部质量门禁通过 |
| `publication_ready=true` | 允许在显式请求下发布系数；仍需确认数据授权和版本 |
| `completed_quality_passed` | 流程完成且校准质量通过 |
| `completed_quality_blocked` | 有样本但质量不足，只保留诊断结果 |
| `incomplete_no_calibration_samples` | 没有形成可用校准样本 |
| `blocked_quality_gate_failed` | 用户请求发布，但发布被质量门禁阻断 |

“存在样本”与“校准有效”已明确分离。鲁棒拟合样本为 0、留出样本不足、误差过大或系数明显异常时，不会再生成或发布运行时系数。

## 4. 默认质量门禁

默认阈值是执行前可见、可配置的初始工程门槛，不是论文结果出来后再调整的参数：

| 检查 | 默认要求 |
| --- | ---: |
| 拟合样本数 | ≥ 30 |
| 独立留出验证样本数 | ≥ 10 |
| 留出比例 | 20%（按方向和 A/B 聚合口径分层） |
| 校准系数范围 | 0.2–5.0 |
| 留出集中位 APE | ≤ 30% |
| 留出集 P90 APE | ≤ 60% |
| 留出集 WAPE | ≤ 30% |
| 样本外改善 | 校准后中位 APE 严格小于未校准值 |
| 训练/验证样本重叠 | 必须为 0 |

全局与分组口径都在验证集上报告，但质量门禁只采用运行前通过 `--validation-model` 指定的口径，并记录 `selected_validation_mode`。默认值为 `grouped`，分组样本不足时按既有规则回退全局系数。禁止查看验证误差后再选择较好口径。阈值需要调整时，应先由项目方基于计量精度和论文目标确认，并将参数写入运行清单，不能依据本次结果倒推阈值。

## 5. 运行命令

诊断运行不会修改正式运行数据：

```powershell
python run_project.py calibrate-energy `
  --smart-meter-dir <电表原始目录> `
  --data-dir <冻结模型数据目录> `
  --output-dir paper/experiments/calibration/<数据版本> `
  --overlap-policy exclude `
  --representative-samples
```

只有质量门禁已经通过并完成审核时，才追加：

```powershell
--publish-calibration
```

发布前建议显式写出阈值，例如：

```powershell
--min-fit-samples 30 --min-validation-samples 10 `
--validation-fraction 0.20 `
--validation-model grouped `
--max-median-ape-pct 30 --max-p90-ape-pct 60 --max-wape-pct 30 `
--min-scale 0.2 --max-scale 5.0
```

拿到另一日期或来源批次的已对齐样本后，建议追加：

```powershell
--validation-alignment-csv <外部批次>/arc_energy_vs_meter_samples.csv
```

此时当前流水线样本全部用于拟合，质量指标只在外部文件上计算；输入清单会同时记录该文件的 SHA-256。

## 7. 与正式实验总控衔接

正式实验可将通过质量门禁的摘要作为证据输入：

```powershell
python run_project.py formal-experiment-suite `
  --data-dir <正式运行时数据目录> `
  --source-dir <正式来源目录> `
  --timetable <正式运行图> `
  --output-root <正式实验输出目录> `
  --window-id <评价窗口> `
  --calibration-summary <校准输出>/pipeline_summary.json `
  --require-calibration
```

总控会记录摘要路径、SHA-256、质量状态、失败项和留出误差；要求校准但质量未通过时，正式实验会在运行优化前被阻断。该证据不会隐式缩放车辆牵引或再生功率。若今后决定把系数用于动力学模型，必须另行定义其物理作用位置、牵引/再生边界和版本，并做独立消融验证。

## 8. 结果解释

- MAE/RMSE 反映绝对 kWh 偏差，适合判断实际量级；
- bias 和 bias_pct 反映系统性高估或低估；
- MAPE、中位 APE 和 P90 APE 反映典型与尾部相对误差；
- WAPE 适合避免小电量样本放大百分比误差；
- R² 只表示变化趋势拟合程度，不能代替能量偏差指标；
- 留出误差才用于发布判断，同一样本拟合后的误差只用于诊断。

没有可匹配电表数据时，论文只能表述为“基于正式输入参数的仿真比较”；质量门禁通过后，可以表述为“模型已在独立留出电表样本上完成误差验证”，但优化方案仍需现场或历史回放数据验证。

## 9. 当前数据实跑结论

2026-09-04 对现有全量电表源执行了未发布运行，结果保存在 `paper/experiments/model_meter_calibration_current/`：

| 项目 | 当前结果 |
| --- | ---: |
| 时间窗匹配 | 1721 |
| 高可信候选 | 1172 |
| 主线代表样本 | 48 |
| `fit_core` 鲁棒样本 | 16 |
| 拟合/留出验证 | 13 / 3 |
| 未校准留出集中位 APE | 62.37% |
| 校准后留出集中位 APE | 68.37% |
| 校准后 P90 APE / WAPE | 299.88% / 98.59% |

本次质量门禁未通过：拟合和验证样本数不足，误差超过阈值，且样本外中位误差没有改善。因此当前历史实验系数不得升级为正式系数，流水线没有生成或发布新系数。该结论是对现有数据校准能力的真实审计结果，不是程序失败。
