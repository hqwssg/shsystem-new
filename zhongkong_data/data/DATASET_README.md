# 朔黄重空协调数据集

本目录是项目代码 `ruoyi-energy` 的 `shuohuang_demo / v1` 输入版本。文件名和相对目录必须保持不变；仓库内生成器会将全部文件和关系数据写入自包含数据库迁移。

## 文件组成

- 线路基础：`车站主数据.csv`、`车站.csv`、`车站_范围外.csv`、`车站能力.csv`、`区间.csv`、`坡度.csv`、`曲线.csv`、`线路参数.json`
- 运行与能力：`供电臂.csv`、`追踪间隔.csv`、`技术作业时分.csv`、`技术作业时分_范围外.csv`、`作业适用范围.csv`、`作业条件.json`、`资源规则.json`
- 列车与储能：`列车参数.csv`、`编组模式.csv`、`储能区段.csv`、`储能参数.json`
- 校准与样本：`电表标定样本.csv`、`电表区间样本.csv`、`电表标定摘要.json`、`能量标定.json`
- 平台联调：`platform/运行图.xlsx`、`platform/联合参数区间.json`、`platform/滚动扰动回放.json`
- `构建摘要.json`：数据构建来源和范围说明

## 数据边界

主线范围为朔黄线 K0-K583.003；黄万线等范围外记录仅作为背景资料，不参与当前主线模型。储能参数、列车牵引特性、部分能力约束和运行图属于规划/联调占位数据；电表标定样本属于实验性校准数据。正式工程使用前必须替换为经过确认的数据版本。

## 导入

在仓库根目录执行 `python tools/zhongkong/generate_dataset_sql.py`。生成的 `sql/carbon-energy/V5__shuohuang_full_dataset.sql` 按项目代码、版本代码和文件摘要幂等导入，不覆盖已有不同内容的版本。服务器更新包会自动包含并执行该迁移。
